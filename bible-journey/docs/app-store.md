# פרייזר באפסטור: מה מוכן, מה חסר ומה צריך להחליט

## מה כבר מוכן בקוד

- אייקון 1024×1024 (`assets/app/icon.png`), מסך פתיחה, אייקון אדפטיבי לאנדרואיד.
- שם האפליקציה בעברית ("פרייזר") ובאנגלית, וטקסטי ההרשאות למיקרופון ולזיהוי דיבור בשתי השפות (`locales/`).
- גרסה 1.0.0, מזהה `com.phraser.biblejourney`, הצהרת הצפנה (`ITSAppUsesNonExemptEncryption: false`) כדי שלא תישאל על כך בכל העלאה.
- מוזיקה, צלילים ורטט באייפון ובאנדרואיד. המשחק מכבד את מתג ההשתקה ואינו עוצר מוזיקה אחרת שמתנגנת.
- פרופילי בנייה ב־`eas.json`: `simulator`, `preview`, `production`.
- חבילת ה־JavaScript של iOS נבנית בהצלחה (`npx expo export --platform ios`).

## מה לא נבדק

על המחשב הזה אין Xcode, ולכן האפליקציה עדיין לא רצה על סימולטור או על אייפון. לפני הגשה צריך לבדוק על מכשיר אמיתי, לפי הסדר הזה:

1. כיוון הכתיבה. המסכים קובעים בעצמם ימין־לשמאל, ובהפעלה מבוטל ההיפוך האוטומטי של המערכת (`app/_layout.tsx`). זה הדבר הראשון לוודא באייפון שמוגדר לעברית.
2. צליל: המוזיקה מתחילה במסך הפתיחה, נחלשת בזמן חידה, נעצרת כשיוצאים מהאפליקציה. אם העוצמה לא מתאימה, משנים את `NATIVE_GAIN` ב־`src/sound.native.ts`.
3. רטט בתשובה נכונה, בתשובה שגויה ובסיום נקודת ציון.
4. תשובה בקול (מיקרופון וזיהוי דיבור) ומקלדת עברית בחידות ההקלדה.
5. אייפד: האפליקציה מוגדרת כתומכת באייפד, ולכן אפל תדרוש צילומי מסך גם ממנו.

## הצעדים שלך

1. חשבון Apple Developer (99 דולר לשנה) וחשבון Expo (חינם).
2. בתיקיית `bible-journey`:

```bash
npm install -g eas-cli
```

```bash
eas login
```

```bash
eas build --platform ios --profile production
```

```bash
eas submit --platform ios
```

הבנייה נעשית בענן של Expo, כך שלא צריך Xcode. בפעם הראשונה `eas` ייצור את התעודות ואת רשומת האפליקציה ב־App Store Connect.
3. ב־App Store Connect: טקסט העמוד, צילומי מסך, דירוג גיל, פרטיות, ואז TestFlight לבדיקה על מכשיר לפני ההגשה לבדיקה של אפל.

## החלטות שצריך לקבל

- **קטגוריית "ילדים" או "חינוך".** יש קבוצת גיל 4–7, אבל המשחק פונה גם לבני נוער ולמבוגרים. בקטגוריית הילדים אפל דורשת "שער הורים" לפני כל קישור חיצוני (כרגע "קריאת המקור המקראי" פותח דפדפן), ומגבילה שירותי צד שלישי. ההמלצה: קטגוריה ראשית חינוך, משנית משחקי טריוויה, דירוג גיל 4+, בלי קטגוריית הילדים. אם בכל זאת רוצים קטגוריית ילדים, צריך להוסיף שער הורים לקישור ולתשובה בקול.
- **זיהוי דיבור.** באייפון הדיבור עשוי להישלח לשרתי אפל. צריך לציין זאת במדיניות הפרטיות, או לוותר על התכונה בגרסה הראשונה.
- **מדיניות פרטיות.** חובה כתובת אינטרנט. האפליקציה לא אוספת מידע (אין חשבונות, שרת, פרסומות או אנליטיקה, וההתקדמות נשמרת במכשיר בלבד), כך שבשאלון הפרטיות התשובה היא "לא נאסף מידע".
- **מחיר.** כרגע אין רכישות. אסימונים מרוויחים רק במשחק.
- **גודל.** כ־93MB, כמעט הכול איורים. תקין להורדה ברשת סלולרית.

## טיוטה לעמוד האפליקציה

**שם:** פרייזר: מסע בתנ״ך

**כותרת משנה (עד 30 תווים):** חידות תמונה מסיפורי התנ״ך

**תיאור:**

יוצאים למסע בתנ״ך עם ברווז סקרן. בוחרים קבוצת גיל ומלווה (משה, נח או שמשון), מתבוננים באיור, מזהים את הסיפור ועונים על שאלות שמעמיקות בו.

- 7 מפות, 28 נקודות ציון ו־140 חידות מאוירות בכל מסע, בסדר שונה בכל פעם
- ארבע רמות: גילאי 4–7, 8–12, 13–17 ומבוגרים, כל אחת עם שאלות וסיפורים משלה
- כוכבים על כל נקודת ציון, רצף תשובות נכונות ואוצרות נסתרים בדרך
- משחק ליחיד או לשניים באותו מכשיר
- אחרי כל תשובה: הסבר קצר עם מראה המקום בתנ״ך
- עברית ואנגלית, בלי פרסומות, בלי הרשמה, ועובד גם בלי אינטרנט

**מילות מפתח:** תנך,תורה,חידון,חידות,ילדים,סיפורי התנך,משה,נח,שמשון,טריוויה,לימוד,חינוך

## צילומי מסך שכדאי להכין

מסך הספר הפותח, חידת תמונה עם אפשרויות, כרטיס "נכון!" עם ההסבר, המפה עם הברווז בדרך, סיכום נקודת ציון עם שלושה כוכבים, ובחירת קבוצת הגיל. גדלים נדרשים: אייפון 6.9 אינץ׳ ואייפד 13 אינץ׳.
